Verileri Dışa Aktar

Yaptığınız tüm değişiklikler şu anda yerel tarayıcınızın belleğinde (localStorage) tutulmaktadır. Değişiklikleri kalıcı kılmak ve Render sunucunuza bağlamak için aşağıdaki JSON çıktısını indirin ve projenin kök dizinine portfolio-data.json olarak kaydedin.

🔗 Render & Backend Entegrasyon Rehberi

Geliştirdiğimiz admin paneli tamamen API uyumludur. Render üzerinde Node.js/Express, Python veya Go gibi herhangi bir backend çalıştırdığınızda yapmanız gereken tek şey:

  1. portfolio-data.json dosyasını sunucunuzda okuyup yazacak basit bir `POST /api/portfolio` ve `GET /api/portfolio` endpoint'i yazmak.
  2. admin.js dosyasındaki local storage kaydetme satırlarını bu API istekleriyle değiştirmek.

Kodlarımız bu entegrasyonu en kolay şekilde yapabilmeniz için temiz ve bağımsız fonksiyonlarla tasarlanmıştır.
